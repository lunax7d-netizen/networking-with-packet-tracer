# Examine Packets in the Small Office

## Overview

This lab explores network traffic within a small office environment
using Cisco Packet Tracer's simulation capabilities.

## Objectives

- Observe network traffic
- Examine packets as they travel through the network
- Understand packet flow between devices
- Analyze network communication

## Tools

- Cisco Packet Tracer

## Skills Demonstrated

- Packet analysis
- Network traffic analysis
- Network troubleshooting
- Understanding packet flow
- Cisco Packet Tracer
