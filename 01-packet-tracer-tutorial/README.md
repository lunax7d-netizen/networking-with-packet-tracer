# Creating a Simple Network

## Overview

This lab demonstrates the creation of a basic network using Cisco
Packet Tracer. The network consists of end devices connected through
a network switch.

## Objectives

- Build a basic network topology
- Connect end devices to a switch
- Configure network devices
- Assign IP addresses to end devices
- Test connectivity between devices

## Network Topology

The network consists of:

- 1 Cisco switch
- 2 PCs
- Ethernet connections

## Configuration

The end devices were configured with IPv4 addresses within the same
network.

Example:

| Device | IP Address | Subnet Mask |
|---|---|---|
| PC1 | 192.168.1.10 | 255.255.255.0 |
| PC2 | 192.168.1.11 | 255.255.255.0 |

## Testing

Connectivity was tested using ICMP ping between the end devices.

Successful communication confirmed that the basic network was
configured correctly.

## Skills Demonstrated

- Cisco Packet Tracer
- Basic network topology design
- Ethernet connectivity
- IPv4 addressing
- Switch connectivity
- Network troubleshooting
- Connectivity testing
