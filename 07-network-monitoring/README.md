# Monitor Your Network Using a Network Controller

## Overview

This lab explores network monitoring and management using a network
controller in Cisco Packet Tracer.

## Objectives

- Monitor network devices
- Observe network status
- Use network management capabilities
- Understand centralized network monitoring

## Tools

## Skills Demonstrated

- Network monitoring

- Network troubleshooting
- Network administration
- Cisco Packet Tracer
