# Edit Topologies

## Overview

This lab focuses on creating and modifying network topologies using
Cisco Packet Tracer.

## Objectives

- Modify an existing network topology
- Add and remove network devices
- Configure device connections
- Test the resulting topology

## Tools

- Cisco Packet Tracer

## Skills Demonstrated

- Network topology design
- Network device configuration
- Device connectivity
- Cisco Packet Tracer
