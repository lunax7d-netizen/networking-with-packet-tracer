# Connect Devices Using Wireless Technologies

## Overview

This lab demonstrates how to connect network devices using wireless
technologies in Cisco Packet Tracer.

## Objectives

- Configure wireless network connectivity
- Connect devices using wireless technologies
- Understand wireless network components
- Test connectivity between devices

## Tools

- Cisco Packet Tracer

## Skills Demonstrated

- Wireless networking
- Network device configuration
- Network connectivity
- Cisco Packet Tracer
- Network troubleshooting
