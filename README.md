# Packet Tracer Tutorial

## Overview

This lab introduces the Cisco Packet Tracer environment and the
fundamental concepts required to build and interact with simulated
networks.

## Objectives

- Become familiar with the Cisco Packet Tracer interface
- Add and connect network devices
- Build a basic network topology
- Explore device configuration
- Test network connectivity

## Tools

- Cisco Packet Tracer

## Skills Demonstrated

- Cisco Packet Tracer
- Network topology creation
- Network device connectivity
- Basic network configuration
- Network simulation
