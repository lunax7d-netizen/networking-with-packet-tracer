# Create Realistic Structured Cabling

## Overview

This lab demonstrates the creation of a realistic physical network
topology using structured cabling in Cisco Packet Tracer.

## Objectives

- Design a physical network topology
- Connect networking devices using appropriate cables
- Understand structured network cabling
- Organize network devices within a physical environment

## Tools

- Cisco Packet Tracer

## Skills Demonstrated

- Physical network design
- Structured cabling
- Network topology design
- Cisco Packet Tracer
